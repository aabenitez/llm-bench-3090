# =============================================================================
#  Lista de modelos a evaluar (GGUF descargados automáticamente de Hugging Face)
#  Pensada para: 1 o 2x RTX 3090 (24/48 GB) + 32/64 GB DDR5 + Ryzen 7800X3D / 9950X3D
# =============================================================================
#  Formato (separado por "|"):
#    nombre | repo_hf:cuant | tokenizer_hf | contexto | ram_min_gb | args_extra | gpus_min | args_2gpu
#
#  - nombre        : alias corto (sin espacios), se usa en archivos y gráficos.
#  - repo_hf:cuant : lo que recibe "llama-server -hf" (repo GGUF + cuantización).
#  - tokenizer_hf  : repo HF con el tokenizer original (lo usa llama-benchy para
#                    construir prompts de longitud exacta). Usar repos sin acceso
#                    restringido (por eso unsloth/... en Gemma, Llama y Mistral).
#  - contexto      : tokens de contexto POR SLOT. Las profundidades (--depth) que
#                    no entren (depth + pp + tg > contexto) se omiten para ese modelo.
#  - ram_min_gb    : RAM de sistema mínima. Si tu PC tiene menos, se salta.
#  - args_extra    : flags extra para llama-server (ej. caché KV cuantizada o
#                    "--n-cpu-moe N" para descargar expertos MoE a la CPU/RAM).
#  - gpus_min      : (opcional, defecto 1) 2 = solo se prueba en modos de 2 GPUs.
#  - args_2gpu     : (opcional) reemplaza args_extra en los modos de 2 GPUs.
#                    "-" = sin flags extra. Útil para bajar --n-cpu-moe con 48 GB.
#
#  Notas:
#  - En el modo 2gpu-tensor se quitan -ctk/-ctv (no admite caché KV cuantizada)
#    y muchos MoE no están soportados: esos fallarán ahí y se registran como error.
#  - Líneas que empiezan con "#" se ignoran. Comentá/descomentá a gusto.
# =============================================================================
